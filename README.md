# PLT Save – Tải video Facebook, Douyin, YouTube

Trang web con của **Phát Lộc Tech**: https://save.phatloctech.vn

- Chọn chất lượng (hiện dung lượng) → **Tải về máy** hoặc **Gửi qua Telegram** (bot, ≤50MB)
- Extension Chrome cho máy tính: `download/plt-taivideo-ext.zip`
- Chạy trên Vercel (Python serverless + yt-dlp)
